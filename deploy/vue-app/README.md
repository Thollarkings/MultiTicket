# TicketFlow - Vue.js Implementation

Vue.js version of the multi-framework ticket management application.

## Status
✅ Landing page implemented with identical design system as React version

## Features Demonstrated
- Wave hero background with SVG
- Decorative circles overlapping hero section  
- Card-style components with shadows and rounded corners
- Max-width 1440px centered layout
- Responsive design for mobile and tablet
- Consistent color scheme and typography

## Tech Stack
- Vue.js 3
- Vite
- CSS3 with custom properties

## Setup
```bash
npm install
npm run dev
